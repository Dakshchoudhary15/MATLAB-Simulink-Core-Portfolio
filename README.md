## 📂 Featured Projects

### 1. Modular Hybrid Renewable Microgrid Simulation
* **Overview:** Designed a system-level behavioral simulation combining Photovoltaic (PV), Wind Energy Conversion (WEC), PEM Fuel Cell, and Li-ion Battery storage subsystems.
* **Key Implementation:** Modeled environmental and load variations (irradiance, temperature, wind speed, current demand) using mathematical blocks and transfer function filters.
* **Visualization:** Utilized Mux blocks and multi-channel dashboard scopes to monitor generation and storage dynamics in real-time.

### 2. Closed-Loop DC Motor Speed Control Simulation
* **Overview:** Engineered a feedback control system using PID controllers and transfer function plant models to regulate DC motor speed against step reference commands.
* **Key Implementation:** Implemented negative feedback loops to eliminate steady-state error and stabilize transient response behaviors.
* **Validation:** Verified system stability and tracking accuracy using scope waveform outputs.

### 3. DC-DC Buck Converter Simulation
* **Overview:** Modeled an open-loop step-down power electronic converter using switching blocks and LC filter configurations.
* **Key Implementation:** Analyzed voltage conversion ratios and transient ripple filtering performance under dynamic load steps.
